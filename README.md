# Self-Organized Charging Infrastructure — Supplementary Materials

This repository provides supplementary materials for the journal article:
**Self-Organized Charging Infrastructure for Efficient Crazyflie Drone Swarm Deployment Using IR-Based Tracking**.

## Repository Structure

- [`evaluation-data-and-tools/`](./evaluation-data-and-tool) — recorded datasets and evaluation tools used for empirical experiments.

## Supplementary Content

The supplementary material includes:

- recorded experiment data,
- simulation and real-world comparison scenarios,
- video material of representative runs.

## Related Publications

This work extends the conference publication:

**ARCS 2026 — 39th GI/ITG International Conference on Architecture of Computing Systems**  
24–26 March 2026, Mainz, Germany

- Preprint: [ResearchGate publication](https://www.researchgate.net/publication/401785656_Self-Organized_Charging_Infrastructure_for_Vicon-based_Crazyflie_Drone_Swarms)
